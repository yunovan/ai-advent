# Протокол MCP и агенты

MCP (Model Context Protocol) — открытый протокол, который связывает LLM-приложения
с данными и инструментами. Сервер MCP объявляет инструменты, клиент вызывает их,
а транспорт общается по JSON-RPC: сообщение содержит jsonrpc, method и id, ответ —
result или error с кодом.

## Транспорт и сессии

Обмен идёт по HTTP: клиент отправляет POST на адрес сервера с телом JSON-RPC.
Первым сообщением приходит initialize — запрос на установку сессии. Сервер отвечает
протокольной версией, списком возможностей и своим именем, а в заголовке Mcp-Session-Id
возвращает идентификатор сессии. Дальше клиент подписывает этим идентификатором
все последующие запросы.

Инструменты объявляются через tools/list: каждый инструмент имеет имя, описание и
JSON-схему аргументов. Вызов происходит через tools/call: имя инструмента и объект
с аргументами. Ответ содержит content — массив текстовых блоков с результатом — и
флаг isError.

## Коды ошибок JSON-RPC

- −32700 — не удалось разобрать JSON;
- −32600 — некорректный запрос (например, вызов инструмента без сессии);
- −32601 — метод или инструмент не найден;
- −32602 — неверные параметры: обязательный аргумент не передан, значение
  не того типа;
- −32000 — внутренняя ошибка сервера.

Клиент, получивший error, обязан превратить его в понятное исключение, чтобы агент
не «выдумывал» результат от имени сломанного инструмента.

## Агент поверх инструментов

Агент — это слой между пользовательским запросом и инструментами. Он распознаёт
намерение по маркерам, выбирает инструмент и аргументы, выполняет вызов и
формулирует ответ на русском языке. Если LLM недоступен — агент честно возвращает
сырой результат инструмента вместо выдумки.

Инструменты в этом проекте живут на разных серверах: планировщик дней 18
объявляет scheduler_* (напоминания, сбор данных, сводки), витрина дня 19 —
search, summarize и saveToFile. Оркестратор дня 20 держит единый каталог и сам
становится сервером MCP, маршрутизируя вызовы. День 21 добавляет в эту экосистему
локальный индекс документов с инструментами index_ingest, index_search,
index_compare и index_status.
