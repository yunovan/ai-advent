Три стратегии контекста

Sliding Window, Sticky Facts и Branching — три способа держать диалог в пределах контекстного окна. Выберите стратегию, запустите диалог и сравните: сколько токенов, какая стабильность, насколько удобно.

Sliding WindowПоследние N сообщений — всё остальное отбрасывается.
Sticky FactsБлок фактов (ключ-значение) + последние N сообщений.
BranchingВетки диалога от checkpoint'а.

Подсказки: 1) Sliding Window — уменьшайте окно, модель начнёт «забывать»; 2) Facts — добавляйте ключ-значение через UI, агент использует их в промпте; 3) Branching — сохраните checkpoint, создайте ветку, ведите параллельные диалоги; 4) Сравните стратегии на одной задаче (например, сбор ТЗ 10–15 сообщений) через «Прошлые диалоги». CLI: ./gradlew bootRun --args="--day=10 --start --strategy=sliding --window=6 --cli".
