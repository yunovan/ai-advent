Подключение MCP

Вместе с приложением стартует собственный MCP-сервер на порту 8090, а приложение подключается к нему как MCP-клиент и получает список доступных инструментов.

Инструменты MCP

Вызвать инструмент

MCP стартует вместе с приложением: http://localhost:8090/mcp. Сценарий видео: 1) «Проверить соединение» — приложение устанавливает MCP-соединение и показывает версию протокола, имя и версию сервера; 2) «Список инструментов» — MCP возвращает day16_sum и day16_upper; 3) вызовите day16_sum с числами — результат придёт из MCP. CLI: ./gradlew bootRun --args="--day=16 --check --cli", --day=16 --tools --cli, --day=16 --call=day16_sum --arg=a=6 --arg=b=7 --cli.
