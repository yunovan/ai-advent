AI Advent · Day 32

Автоматическое ревью кода

Пайплайн сам анализирует pull request: берёт diff и список изменённых файлов, подтягивает релевантный контекст проекта из RAG (документация + код) и возвращает ревью: потенциальные баги, архитектурные проблемы и рекомендации. Если локальная модель недоступна, замечания собираются эвристиками.

Запустить ревью

Диапазон сравнивается как base...head; «текущие изменения» — рабочее дерево против HEAD. Ответ содержит секции Потенциальные баги, Архитектурные проблемы, Рекомендации.
Подсказка для видео: 1) ./gradlew bootRun --args="--day=32" и http://localhost:8080/day32.html — «Проверить» покажет индекс и модель; 2) «Показать» под списком изменённых файлов; 3) «Ревью диапазона» — видно три секции и источники RAG; 4) в CLI: --day=32 --check и --day=32 --review --base=main --out=ai-review.md; 5) в GitHub Actions работает .github/workflows/ai-review.yml на каждый PR.
