AI Advent · Day 15

Контролируемые переходы состояний

У задачи — явные состояния и разрешённые переходы. Ассистент не может «перепрыгнуть» этап: реализация — только после утверждённого плана, завершение — только после проверки. Пауза сохраняет состояние, продолжение после неё корректно.

Создайте задачу, затем управляйте переходами между состояниями. Разрешённые переходы показаны кнопками.
Сценарий видео: 1) создайте задачу «Переезд на Java 21»; 2) попробуйте переход «выполнение» прямо из «планирование» — ассистент его отклонит (нельзя до утверждённого плана); 3) пройдите «план утверждён → выполнение → проверка → готово»; 4) нажмите «Пауза», затем «Продолжить» и отправьте «Продолжай работу» — агент продолжит в том же состоянии. Цепочка: планирование → план утверждён → выполнение → проверка → готово. CLI: ./gradlew bootRun --args="--day=15 --create=\"Задача\" --cli", --task=<id> --transition=выполнение --cli (отклонится), --task=<id> --advance --cli, --task=<id> --pause --cli, --task=<id> --prompt=\"...\" --cli.
