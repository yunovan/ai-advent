AI Advent · Day 19

Композиция MCP-инструментов

Три инструмента — search, summarize, saveToFile — складываются в автоматический пайплайн: поиск → сводная таблица → файл. Модуль проверяет, что результат каждого шага корректно передаётся следующему. Данные живут в data/day19-market.

Соединение агента с MCP

Инструменты MCP

Поиск и сводная таблица

Пайплайн search → summarize → saveToFile

Каждый шаг проверяет переданные данные: search возвращает JSON-список, summarize принимает его и проверяет на пустоту, saveToFile принимает результат summarize и складывает файл в data/day19-market. Пайплайн показывает успех каждого шага.

Сохранённые файлы

Агент (композиция по запросу)

MCP-сервер пайплайна стартует вместе с приложением: http://localhost:9092/mcp. Скрипт видео: 1) «Проверить соединение» — агент подключается к MCP и читает 3 инструмента search, summarize, saveToFile; 2) «Поиск товаров» — инструмент search возвращает JSON-список товаров; 3) «Сводная таблица» — результат search передаётся в summarize, строится таблица «Сравнение по запросу»; 4) «Запустить пайплайн» — весь конвейер выполняется автоматически, каждый шаг подтверждает успех, файл появляется в списке; 5) агент по-русски: «сравни ноутбуки в таблицу», «сохрани телевизоры в файл csv».
