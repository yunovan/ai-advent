Запуск локальной LLM

Ollama установлен локально, модель qwen2.5:3b (1.9 GB, Q4, CPU) отвечает по HTTP API на localhost:11434. Три запроса разной сложности — от приветствия до кода с объяснением сложности.

Скрипт видео: 1) winget install --id Ollama.Ollama --silent и ollama pull qwen2.5:3b — 1.9 GB; 2) «Проверить» — endpoint, версия сервера, установленная модель и её параметры; 3) «Запустить 3 запроса» — простой запрос, объяснение и код: ответы, задержки, токены и скорость генерации; 4) свой запрос в этом же окне; 5) остановить службу Ollama и нажать «Проверить» — честное «сервер запущен: НЕТ».
