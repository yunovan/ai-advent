AI Advent · Day 34

Ассистент для работы с файлами проекта

Ассистент сам инициирует работу с файлами проекта: читает, ищет по нескольким файлам, анализирует, создаёт и изменяет. Работает через файловые инструменты MCP или напрямую через workspace. Минимум 2 сценария, работает с 2–3 файлами, изменения сохраняются или выводятся как diff.

Состояние

Список файлов (fs_list)

Цель для агента

Агент классифицирует цель, составляет план, выполняет fs_* через MCP или локально, собирает контекст, при необходимости вызывает LLM и формирует артефакт/diff.

MCP-инструменты файлового сервера

CLI-примеры: --day=34 --check, --day=34 --run="Найди использования Day34Workspace", --day=34 --run="Проверь инварианты кода" --write, --day=34 --files --prefix=src/main/java.
