AI Advent · Day 33

Ассистент поддержки пользователей

Мини-сервис поддержки: отвечает на вопросы о продукте по базе знаний (FAQ и документация, локальный RAG-индекс) и учитывает контекст пользователя и обращения, который получает из CRM по MCP. Пример: «Почему не работает авторизация?» — ассистент поднимет тикет T-1001, его переписку, тариф клиента и ответит со ссылками на документацию.

Состояние ассистента

База знаний (корпус RAG)

CRM: пользователи

CRM: обращения

Задать вопрос ассистенту поддержки

Ассистент вызовет инструменты CRM по MCP (crm_ticket, crm_user, crm_user_tickets), найдёт подходящие разделы базы знаний и ответит локальной моделью qwen2.5:3b. Если модель недоступна — ответ собирается из базы знаний.

MCP-инструменты CRM

Вызвать инструмент CRM по MCP

Вызов идёт по MCP JSON-RPC на встроенный сервер дня 33. Инструменты: crm_user, crm_ticket, crm_user_tickets, crm_search_tickets, crm_open_tickets.

    


    
Подсказка для видео: 1) ./gradlew bootRun --args="--day=33" и
        http://localhost:8080/day33.html — «Проверить» покажет базу знаний, CRM и MCP;
        2) выберите обращение T-1001, задайте «Почему не работает авторизация?» —
        видно контекст тикета и источники docs;
        3) вызовите crm_ticket и crm_search_tickets во встроенном MCP;
        4) в CLI: --day=33 --check, --day=33 --tickets,
        --day=33 --ask="..." --ticket=T-1001.
