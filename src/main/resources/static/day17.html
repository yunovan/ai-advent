Первый инструмент MCP

Собственный MCP-сервер «трекер» (mock Яндекс.Трекера) с тремя инструментами. Агент разбирает запрос, сам выбирает инструмент, вызывает его по MCP и формулирует ответ.

Инструменты MCP

Агент вызывает инструмент

Собственный MCP-сервер стартует вместе с приложением: http://localhost:9090/mcp. Скрипт видео: 1) «Проверить соединение» — агент подключается к своему MCP-серверу как клиент; 2) «Список инструментов» — агент читает tracker_create_task, tracker_list_tasks, tracker_add_comment по MCP; 3) «создай задачу Привезти стол» — агент сам выбирает инструмент, вызывает его по MCP и даёт ответ. Данные хранятся в data/day17-tasks.
