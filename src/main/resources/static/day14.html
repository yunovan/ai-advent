AI Advent · Day 14

Инварианты и ограничения состояния

Проектные инварианты живут отдельно от диалога. Ассистент обязан учитывать их в рассуждениях и отказываться предлагать решения, которые их нарушают.

Добавить инвариант

Сначала добавьте инварианты, затем задавайте вопросы — ассистент обязан соблюдать их.
Сценарий видео: 1) добавьте инварианты: «стек / База данных / только PostgreSQL», «архитектура / Микросервисы / без монолита», «бизнес / Скидки / максимум 10%»; 2) спросите «Заменим базу данных на MySQL?» — ассистент должен отказаться и объяснить, какой инвариант нарушен; 3) спросите «Добавим индекс по email?» — решение в рамках стека будет принято. CLI: ./gradlew bootRun --args="--day=14 --category=стек --title=\"База данных\" --description=\"только PostgreSQL\" --cli", --day=14 --invariants, --day=14 --prompt=\"Заменим на MySQL?\" --cli.
