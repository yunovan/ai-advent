AI Advent · Day 20

Оркестрация MCP-серверов

Оркестратор регистрирует два независимых MCP-сервера — планировщик (день 18, порт 9091) и витрину (день 19, порт 9092) — сам является MCP-сервером на порту 9093, маршрутизирует любой инструмент на правильный сервер и выполняет длинные флоу с инструментами разных серверов, передавая результат каждого шага следующему.

Соединение оркестратора

Маршрутизация инструмента

Tools: search, summarize, saveToFile живут на сервере market; scheduler_* — на сервере scheduler. Оркестратор знает, куда идти.

Длинный флоу с инструментами разных серверов

Флоу market-report: search → summarize → saveToFile (сервер market), затем scheduler_add_reminder (сервер scheduler) с путём к файлу из шага 3 — результат предыдущего шага подставляется как {0}, {1}, {2}. Файл ложится в data/day19-market.

Агент (оркестрация по запросу)

Скрипт видео: 1) «Проверить соединение» — оркестратор подключается к обоим серверам и показывает их (scheduler, market); 2) каталог инструментов — все инструменты двух серверов в одном списке; 3) «Маршрутизировать» — инструмент search отправляется на сервер market, scheduler_summary — на scheduler; 4) «Запустить флоу» market-report — результат search передаётся в summarize, затем в saveToFile, а путь к файлу шага 3 попадает в напоминание планировщика шага 4 (видно подстановку {0}/{1}/{2}); 5) агент по-русски: «составь полный отчёт ... и сохрани в файл csv», «сводку по событиям планировщика», «сравни смартфоны в таблицу».
