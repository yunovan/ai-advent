AI Advent · Day 31

Ассистент разработчика

Ассистент понимает проект: отвечает на вопросы о структуре по документации (README.md и папка docs, локальный RAG-индекс), а текущее состояние репозитория получает по MCP. Команда /help объединяет оба источника и отвечает локальной моделью.

Состояние ассистента

Документация проекта (корпус RAG)

MCP-инструменты проекта

Спросить ассистента (/help)

Ассистент запрашивает git-контекст через MCP, находит релевантные разделы документации и отвечает локальной моделью qwen2.5:3b. Если модель недоступна — ответ собирается из найденных фрагментов.

Инструменты git через MCP

Вызов идёт по MCP JSON-RPC на встроенный сервер дня 31. Инструмент git_branch — обязательный минимум подключения ассистента к проекту.

    


    
Подсказка для видео: 1) ./gradlew bootRun --args="--day=31" и
        http://localhost:8080/day31.html — «Проверить» покажет ветку, документацию и MCP;
        2) задайте вопрос о структуре проекта в «Спросить» — видно найденные источники docs;
        3) вызовите git_branch/git_status во встроенном MCP-клиенте;
        4) в CLI: --day=31 --check, --day=31 --tools,
        --day=31 --git=branch, --day=31 --help="...".
