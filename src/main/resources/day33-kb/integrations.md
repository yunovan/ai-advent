# Интеграции и публичный API

«Облако Задач» предоставляет публичный REST API и вебхуки для интеграции со внешними системами.

## Ключи API

Ключ API создаётся в разделе «Настройки → Интеграции → API». Ключ показывается один раз,
поэтому храните его в секрете. Каждому ключу назначаются права (scope) и IP-ограничения.

## Вебхуки

Вебхуки отправляются при событиях `task.created`, `task.updated`, `task.completed` и
`comment.created`. Подпись запроса проверяется заголовком `X-Signature` (HMAC-SHA256).

## Лимиты

- 600 запросов в минуту на организацию.
- До 10 одновременных вебхуков; при недоставке выполняется 5 повторных попыток с
  экспоненциальной задержкой.

## Частые проблемы интеграции

- `401 unauthorized` — ключ отозван или передан без заголовка `Authorization`.
- `403 forbidden` — у ключа нет нужного scope.
- `429 too_many_requests` — превышен лимит запросов.
